# Karan Rajput

Co-founder and forward-deployed engineer in Pune, India. I build customer-facing AI systems end to end — agents, backend, frontend, infra, and rollout — and run them in production.

Currently building [CallMissed](https://callmissed.com), and co-founding [FreeToChat](https://freetochat.app) and [TecnoMate](https://tecnomate.in). Not looking for a job; open to partnerships, design-partner intros, and product collaborations.

## What I'm building

**CallMissed** — an AI-native CRM and customer support platform. It handles engagement across WhatsApp, voice, email, and web chat in 22 Indian languages, with a unified API layer that other products build on. Infra runs on Azure, Cloudflare, and GCP; LLMs come from Azure OpenAI with multi-model routing; voice runs through Deepgram, Sarvam, Cartesia, and LiveKit. Live at [callmissed.com](https://callmissed.com) ([app](https://app.callmissed.com), [docs](https://docs.callmissed.com)).

**FreeToChat** — a multi-model chat workspace that runs on the CallMissed APIs, with streaming responses and model routing handled by the platform. Live at [freetochat.app](https://freetochat.app).

**TecnoMate** — an electronics marketplace where the AI agents run on the CallMissed APIs: a RAG product catalog, Razorpay payments, and agent orchestration over 65+ endpoints. Live at [tecnomate.in](https://tecnomate.in).

## Selected proof

- Meta Tech Provider and Meta Business Partner — WhatsApp Business Platform, embedded signup, and client onboarding.
